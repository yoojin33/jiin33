OWASP Top 10 (2021~ )

웹 애플리케이션 보안의 표준, 10대 치명적 위협과 실무 대응 전략입니다.

Top 01

Broken Access Control (취약한 접근 제어)

권한이 없는 사용자가 타인의 데이터에 접근하거나 관리자 기능을 사용하는 결함입니다.

위협: 사용자 ID 조작만으로 타인의 개인정보 조회 및 수정

➔ 대응: 모든 요청에 대해 서버측에서 사용자 권한을 재검증하는 로직을 필수 적용합니다.

Top 02

Cryptographic Failures (암호화 실패)

민감 정보가 평문으로 저장되거나 취약한 암호 알고리즘을 사용하여 데이터가 노출되는 상태입니다.

위협: 데이터 전송 시 평문 노출 또는 취약한 해시 함수 사용

➔ 대응: TLS(HTTPS)를 강제 적용하고, Argon2나 bcrypt 같은 강력한 해시 알고리즘을 사용합니다.

Top 03

Injection (인젝션)

악의적인 데이터가 명령어나 쿼리의 일부로 실행되어 DB 정보를 탈취하거나 서버를 조작하는 공격입니다.

위협: SQL 인젝션을 통한 로그인 우회 및 데이터베이스 탈취

➔ 대응: 매개변수화 쿼리(Prepared Statement)를 사용하여 입력값을 데이터로만 처리합니다.

Top 04

Insecure Design (안전하지 않은 설계)

구현 단계가 아닌 기획 및 설계 단계부터 보안 고려가 부족하여 발생하는 논리적 결함입니다.

위협: 비즈니스 로직 설계 미흡으로 인한 프로세스 우회 공격

➔ 대응: 개발 초기 단계부터 위협 모델링을 실시하고 보안 설계 가이드라인을 준수합니다.

Top 05

Security Misconfiguration (보안 설정 오류)

기본 관리자 계정 방치, 불필요한 포트 개방, 상세한 에러 메시지 노출 등 설정상의 허점입니다.

위협: 서버 오류 시 전체 파일 경로가 포함된 상세 정보 노출

➔ 대응: 불필요한 기능을 제거하고 상세 에러 메시지가 외부에 노출되지 않도록 설정합니다.

Top 06

Vulnerable and Outdated Components (취약한 구성 요소)

보안 패치가 중단되었거나 이미 취약점이 발견된 라이브러리 및 프레임워크를 사용하는 경우입니다.

위협: 취약점이 발견된 구버전 라이브러리를 통한 서버 침투

➔ 대응: 주기적인 종속성 검사를 실시하고 최신 보안 패치를 즉시 적용합니다.

Top 07

Identification and Authentication Failures (식별 및 인증 실패)

취약한 비밀번호 정책이나 세션 관리 미흡으로 사용자 계정을 탈취당하는 결함입니다.

위협: 무차별 대입 공격(Brute Force)을 통한 계정 탈취

➔ 대응: 2단계 인증(MFA)을 도입하고 세션 타임아웃과 강력한 비밀번호 정책을 설정합니다.

Top 08

Software and Data Integrity Failures (소프트웨어 및 데이터 무결성 결함)

업데이트 시 무결성 검증 없이 코드를 신뢰하여 악성 코드가 삽입되는 취약점입니다.

위협: 출처가 불분명한 플러그인을 통한 악성코드 유입

➔ 대응: 디지털 서명을 통해 소스코드 무결성을 검증하고 역직렬화 공격을 방지합니다.

Top 09

Security Logging and Monitoring Failures (보안 로깅 및 모니터링 실패)

공격 시도를 기록하지 않거나 감시하지 않아 침해 사고를 조기에 발견하지 못하는 상태입니다.

위협: 침해 사고 발생 후에도 원인 파악 및 증거 확보 불가능

➔ 대응: 주요 보안 이벤트를 로깅하고 실시간 침입 탐지 및 경보 시스템을 구축합니다.

Top 10

Server-Side Request Forgery (SSRF)

서버가 공격자의 의도대로 내부 자원이나 외부의 임의 주소에 강제로 요청을 보내게 만드는 공격입니다.

위협: 서버를 경유하여 내부 폐쇄망 서비스 공격 및 정보 유출

➔ 대응: 입력된 URL에 대한 화이트리스트 검증을 실시하고 서버 내부망 접근을 제한합니다.
