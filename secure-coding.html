Secure Coding Guide

취약점을 방어하고 안전한 서비스를 구축하기 위한 코딩 수칙입니다.

Defense 01

계정 잠금 및 2단계 인증 (MFA)

무차별 대입 공격을 막기 위해 일정 횟수 이상 로그인 실패 시 계정을 잠그거나, 추가 인증을 요구해야 합니다.

실무 적용: 로그인 시도 제한(Rate Limiting)과 CAPTCHA 도입이 가장 효과적입니다.
Defense 02

경로 검증 및 화이트리스트

사용자 입력값에서 ../ 같은 상위 디렉토리 이동 문자를 제거하고, 허용된 파일명만 읽도록 제한합니다. 

// 안전한 예: 경로 문자 제거
String fileName = input.replaceAll("\\.\\./", "");
Defense 03

CSRF Token 검증

모든 변경 요청(POST, PUT 등)에 서버가 발급한 임의의 토큰을 포함시켜, 실제 사용자가 보낸 요청인지 확인합니다.

원리: 공격자는 서버가 발급한 고유 토큰값을 알 수 없으므로 위조된 요청을 보낼 수 없습니다.
Defense 04

OS 명령어 직접 실행 금지

애플리케이션에서 직접 시스템 명령어를 실행하는 함수(Runtime.exec, system 등) 사용을 지양하고, API를 활용합니다.

Defense 05

쿠키 보안 플래그 설정

세션 쿠키가 자바스크립트로 탈취되거나 평문 통신 중 노출되지 않도록 보안 설정을 강화합니다. 

Set-Cookie: session_id=abc123; HttpOnly; Secure; SameSite=Strict
HttpOnly: 스크립트 접근 차단
Secure: HTTPS 연결에서만 전송
Defense 06

SQL Injection 방어

사용자 입력값을 쿼리문에 직접 연결하지 않고, 구조화된 쿼리(Prepared Statement)를 사용하여 데이터베이스를 보호합니다. 

// Prepared Statement를 활용한 안전한 쿼리
const sql = "SELECT * FROM users WHERE id = ? AND pw = ?";
db.query(sql, [userId, userPw]);
원리: 파라미터 바인딩을 사용하면 입력값이 SQL 명령어가 아닌 단순 '데이터'로 처리되어 공격 구문이 실행되지 않습니다.
Defense 07

XSS (Cross-Site Scripting) 방어

사용자가 입력한 데이터가 브라우저에서 스크립트로 실행되지 않도록 특수문자를 HTML 엔티티로 변환(치환)해야 합니다. 

// HTML 특수문자 이스케이프 처리 (개선된 버전)
function escapeHtml(unsafe) {
  if (typeof unsafe !== 'string') {
    return '';
  }
  
  const entityMap = {
    '&': '&',
    '<': '<',
    '>': '>',
    '"': '"',
    "'": '''
  };
  
  return unsafe.replace(/[&<>"']/g, char => entityMap[char]);
}
Defense 08

안전한 파일 업로드 구현

업로드된 파일이 서버에서 실행되지 않도록 철저한 검증과 권한 분리가 필요합니다. 

const allowedExt = ['.jpg', '.jpeg', '.png'];
const fileExt = path.extname(uploadFile.name).toLowerCase();

if (!allowedExt.includes(fileExt)) {
  throw new Error("허용되지 않는 파일 형식입니다.");
}
const safeFileName = uuidv4() + fileExt;
실무 적용: 화이트리스트 방식으로 허용된 확장자만 업로드하고, 파일명을 난수(UUID)로 변경하며 저장 디렉터리의 실행 권한을 제거합니다.
Defense 09

철저한 인증 및 인가 검증

모든 민감한 페이지와 API 접근 시, 단순히 프론트엔드에서 숨기는 것이 아니라 백엔드 서버 측에서 세션과 권한을 교차 검증해야 합니다. 

// 라우터 접근 시 미들웨어를 통한 서버 측 권한 검증
function requireAdmin(req, res, next) {
  if (req.session && req.session.role === 'admin') {
    next();
  } else {
    res.status(403).send("접근 권한이 없습니다.");
  }
}
