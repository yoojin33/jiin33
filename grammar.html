Structure

HTML5 기본 구조

HTML5 문서를 선언하고 웹 페이지의 기본적인 골격을 형성하는 필수 요소입니다.

<!DOCTYPE html> <!-- HTML5 문서 선언 -->
<html> <!-- 전체 문서를 감싸는 최상위 태그 -->
  <head> <!-- 문서 정보 및 메타데이터 -->
    <meta charset="UTF-8">
    <title>웹페이지 제목</title>
  </head>
  <body> <!-- 실제 화면에 출력되는 콘텐츠 -->
    <h1>본문 제목</h1>
  </body>
</html>
Headings

제목 (HTML Headings)

하나의 제목을 만들 때 쓰이는 요소입니다.

중요도에 따라 6단계로 구분되며, <h1>에서 <h6>로 갈수록 중요도가 낮아집니다.

<h1>가장 중요한 제목</h1>
<h2>두 번째로 중요한 제목</h2>
<h3>세 번째로 중요한 제목</h3>
<h4>네 번째로 중요한 제목</h4>
<h5>다섯 번째로 중요한 제목</h5>
<h6>여섯 번째로 중요한 제목</h6>
Paragraphs

문단 (HTML Paragraphs)

하나의 문단을 만들 때 쓰이는 요소입니다.

<p>첫 번째 문단</p>
Line Break

줄바꿈 (HTML Line Break)

강제적으로 줄바꿈을 하고 싶을 때 사용하는 요소입니다.

<p>첫 번째 문단</p><br />
<p>두 번째 문단</p>
Typography

텍스트 포맷팅 (Text Formatting)

텍스트에 시각적 효과뿐만 아니라 의미(Semantic)를 부여하는 태그들입니다.


태그 기능 및 의미
<b> / <strong> 텍스트 굵게 표시 (strong은 '중요함' 의미 포함)
<i> / <em> 텍스트 이탤릭체 표시 (em은 '강조' 의미 포함)
<mark> 하이라이트(형광펜) 효과
<del> 취소선 표시 (삭제된 텍스트)
Lists

리스트 (HTML Lists)

정보를 나열할 때 사용하며, 목적에 따라 구분됩니다.


순서 없는 리스트 (<ul>)


  • 주로 메뉴 구성에 사용
  • 기본 불렛 포인트 표시

순서 있는 리스트 (<ol>)


  1. 절차나 순서 나열
  2. 숫자, 알파벳 등으로 표시
Tables

표 제작 (HTML Tables)

데이터를 행과 열로 구조화하여 표시합니다.

<table>
  <thead>
    <tr> <th>번호</th> <th>이름</th> </tr>
  </thead>
  <tbody>
    <tr> <td>1</td> <td>Web-Pedia</td> </tr>
  </tbody>
</table>
Media

하이퍼링크 및 이미지 (Links & Images)

웹 페이지의 연결성과 시각적 정보를 담당합니다.

<!-- 하이퍼링크 -->
<a href="주소" target="_blank">새 탭에서 열기</a>

<!-- 이미지 출력 -->
<img src="경로" alt="대체 텍스트" width="300">
💡 Tip: alt 속성은 이미지가 로딩되지 않을 때 보여주는 텍스트로, 웹 접근성에 필수입니다.
Multimedia

오디오 및 비디오(HTML Audio & Video)

HTML5 에서는 외부 플러그인의 도움없이도 멀티미디어 파일을 간단히 사용할 수 있습니다.

<!-- 오디오 -->
<audio style="width: 500px; height: 300px;" controls loop>
  <source src="#" type="audio/mpeg">
  <source src="#" type="audio/ogg">
</audio>

<!-- 비디오 -->
<video style="width: 500px; height: 300px;" controls loop>
  <source src="#" type="video/mp4">
  <source src="#" type="video/ogg">
</video>

CSS 스타일링 가이드

Basics

CSS 기본 문법

CSS는 선택자(Selector)와 선언부(Declaration)로 구성됩니다.

h1 {
  color: blue; <!-- 속성: 값; -->
  font-size: 20px;
}
Selectors

핵심 선택자 (Selectors)

유형 예시 설명
태그 선택자 p { } 모든 p 태그 선택
클래스 선택자 .name { } 특정 class 요소 선택
아이디 선택자 #id { } 유일한 id 요소 선택
Properties

주요 CSS 속성

Box Model


margin : 바깥 여백

padding : 안쪽 여백

border : 테두리

content : 콘텐츠 영역

width : 너비

height : 높이

Text Style


text-align : 가로 정렬

vertical-align : 세로 정렬

text-indent : 들여쓰기

line-height : 줄 간격

white-space : 공백 처리

text-transform : 대소문자 설정

Font Style


font-family : 글꼴

font-size : 글꼴 크기

font-weight : 글꼴 두께

font-style : 글꼴 스타일

letter-spacing : 글자 간격

text-decoration : 텍스트 장식

text-transform : 대소문자 설정

Layout

현대적 레이아웃 (Flex & Grid)

반응형 디자인을 위한 핵심 기술입니다.

/* Flexbox: 1차원 정렬 */
.flex { display: flex; justify-content: center; }

/* Grid: 2차원 격자 */
.grid { display: grid; grid-template-columns: 1fr 1fr; }
Display

디스플레이 (Display)

레이아웃을 제어하기 위한 중요한 속성입니다.


  • none : 제거하지 않고 숨긴다
  • inline : 필요한 폭만 가진다
  • block : 새 줄에서 시작하며 브라우저 전체 폭을 차지한다
Color

색상 (Color)

구분 예시 설명
경계선 색상 border-color: 1px solid 색상명; 요소의 경계선 색상을 설정합니다.
텍스트 색상 color: 색상명; 요소의 텍스트 색상을 설정합니다.
색상 값 표기 color: #ff0000;
color: rgb(255, 0, 0); 		색상 값은 16진수, RGB 등으로 표기할 수 있습니다.
Background

배경 (Background)

구분 예시 설명
배경색 지정 background-color: 색상명; 요소의 배경 색상을 설정합니다.
배경 이미지 지정 background-image: url("경로"); 배경으로 사용할 이미지 경로를 지정합니다.
배경 이미지 반복 여부 및 방향 background-repeat: no-repeat; 배경 이미지의 반복 방식을 설정합니다.
배경 이미지 위치 표기 background-position: center; 배경 이미지의 위치를 설정합니다.
